# Music Wallpaper Prompt Editor（音乐壁纸提示词编辑器）

一个单文件、可离线使用的 HTML 工具，用来生成详细的图像生成提示词，把你自己的照片做成 **Apple Music** 或 **Spotify**"正在播放"风格的手机壁纸。提示词用繁体中文（香港风格）撰写。

这个工具**不会**生成图片、调用任何 API，也不会连接 Apple Music / Spotify，它只负责拼出文字。你把这段文字连同原始照片一起粘贴到支持生成图片的聊天工具（例如 ChatGPT）中即可。

## 使用方法

1. 用任何现代浏览器打开 `index.html`（无需安装、无需服务器、没有依赖）。
2. 选择**音乐平台**（Apple Music 或 Spotify）。
3. 填写歌名、歌手、画面比例、摄影风格和可选开关。
4. 完整的提示词会在右侧实时更新，你也可以直接修改文字。
5. 点击**複製提示詞**（复制），或**複製並開啟 ChatGPT**（复制并打开 ChatGPT），然后上传照片并粘贴提示词。

## 选项

| 分组 | 选项 |
|---|---|
| 平台 | Apple Music、Spotify |
| 画面比例 | 9:16、3:4、1:1、4:5、2:3、9:19.5、16:9 |
| 摄影风格 | 10 种预设（电影感日落、胶片、夜景、黄金时刻、蓝调时刻……） |
| 界面文字 | 繁体中文、英文、原歌曲资料 + 繁体中文界面 |
| 界面文字颜色 | 白色、深色、自动 |
| 界面位置 | 底部、顶部、偏下居中并加渐变 |
| 背景 | 保持原样、轻微模糊、暗角 + 渐变 |
| 强调色 | 平台强调色（红 / 绿）：小、无、更多 |
| 开关 | 保留配饰、扩展背景、专辑封面规则、状态栏、锁屏时钟、无水印、保留清晰细节 |
| 其他 | 自由输入额外要求、下载 `.txt` |

## 说明和限制

- 界面布局是根据 iOS 版 Apple Music 和 Spotify"正在播放"界面的公开描述编写的，图像模型不一定能完全还原。
- 提示词里的播放时间只是装饰，不是真实的播放数据。
- Apple Music 和 Spotify 是各自所有者的商标。本项目是独立项目，与 Apple 或 Spotify 无关，也未获其认可。
